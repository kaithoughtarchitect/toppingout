# Roadmap

What's next, in rough order. Nothing here has a date.

1. **macOS and desktop Linux, verified end to end.** The scripts' self-tests already run on both in CI; next is one full job on each. (A Linux server already runs jobs and night shifts: `SETUP.md` §8b.)
2. **A worked example.** A small public sample repo, one job run start to finish, with every record kept, so you can see a real job before installing.
3. **More builders.** Profiles and pre-flight checks for more builder models (`BUILDER-PROFILES.md`).
