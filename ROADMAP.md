# Roadmap

What's next, in rough order. Nothing here has a date.

1. **macOS and Linux, verified end to end.** The scripts' self-tests already run on both in CI; next is one full job on each.
2. **A worked example.** A small public sample repo, one job run start to finish, with every record kept, so you can see a real job before installing.
3. **A cloud option.** Running the night shift on a server instead of your own machine.
4. **More builders.** Profiles and pre-flight checks for more builder models (`BUILDER-PROFILES.md`).

Ideas and requests: open an issue.
