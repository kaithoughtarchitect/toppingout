Optional add-on

Deep Agents

Only for an AI agent built on LangChain, LangGraph or Deep Agents. /f-setup asks first, and installs it only on yes. Topping Out itself needs none of it.

Needs

Python 3.11+Deep Agents requires it.

Installed for you on yes

  • Version 0.7.29, pinned.
  • Comes with Deep Agents.
  • Comes with LangChain. The skeleton adds its SQLite and Postgres checkpoints.

Optional

  • A free account for tracing and LangGraph Studio; paid hosting later. The add-on needs none of it.
  • /deepSends any agent to the reference before it plans, builds or reviews agent code.
  • deepagents-ref/A wiki checked against the real deepagents code, with checked recipes and a beginner's guide.
  • .mcp.jsonLangChain's live docs server, for what the reference doesn't cover.
  • The skeletonA running agent with six tests and CI. Only for a new project.

Works with LangChain’s open-source tools. The logos are LangChain’s own, shown as supplied; no partnership or endorsement is implied. The docs and the package the add-on cites are fetched at install, not shipped.

Windows notes

  • Line endings. Pin LF in the repo (* text=auto eol=lf in .gitattributes) and set core.autocrlf false there.
  • Git Bash rewrites paths, even HEAD:src/app.py. Prefix with MSYS_NO_PATHCONV=1, or run that call from PowerShell.
  • Headless Chrome screenshots need an absolute output path.
