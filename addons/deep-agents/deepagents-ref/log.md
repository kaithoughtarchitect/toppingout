## [2026-11-09] fix | hidden paths: the fixes from a project's copy brought back
A project running its own copy of this reference (seeded at 0.7.20) found that `*` and `**` never match a path segment starting with `.` (`wcmatch` flags `BRACE | GLOBSTAR`, no `DOTGLOB`) and that an unmatched path is allowed, so a `/**` deny leaves hidden paths readable and writable. Its wiki fixes are merged here: the Gotchas and Interrupt mode lines in `wiki/permissions.md`, the interrupt behaviour in `wiki/human-in-the-loop.md`, constitution rule 7, a `wiki/anti.md` row, the `AGENTS.md` read-only checklist line, and pointers on `agent-setup`, `decisions`, `memory`, `production` and `skills`. Its version-text and project-only lines were left out. The facts were checked on 0.7.20 (2026-10-22 to 25); not re-checked on 0.7.29, where the permission code changed (the symlink check). Re-check them at the next version refresh.
