# model-council

Slash: `/model-council`. Folder: `skills/model-council/SKILL.md`.

Ask a panel of AI models, each answering on its own, to help settle a design choice.

**On site:** Before a job, when you allow it: [[f-survey]] can ask it to settle a design choice that doesn't need the code.

The panel only sees a written brief, never the code. It needs an OpenRouter key.

**When to use it:** When a design choice is stuck between options and you've agreed to let AI models weigh in.
