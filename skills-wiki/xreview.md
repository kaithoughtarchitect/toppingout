# xreview

Slash: `/xreview`. Folder: `skills/xreview/SKILL.md`.

Review another session's work with fresh eyes: list each claim, never rewrite it.

**On site:** The second review: run in a **new session from a different AI company** (codex when the foreman is Claude), by hand or with `scripts/cross-review-dispatch.mjs`.

It starts by confirming it hasn't seen the work before, and it never counts on work the same session wrote.

**When to use it:** When the brief is ready and a session from a different AI company can review the work.
