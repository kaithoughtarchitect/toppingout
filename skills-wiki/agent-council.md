# agent-council

Slash: `/agent-council`. Folder: `skills/agent-council/SKILL.md`.

Ask AI agents that can read the code to help settle a design choice.

**On site:** Before a job, optional: [[f-survey]] can ask it about a choice only the code can answer, if you allow the code to be shared.

A heavier version of [[model-council]]: the agents run on your AI subscriptions and can read the repo.

**When to use it:** When a design choice depends on what's in the code and you've agreed to let agents read it.
