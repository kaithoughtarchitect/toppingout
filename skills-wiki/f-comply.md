# f-comply

Slash: `/f-comply`. Folder: `skills/f-comply/SKILL.md`.

Check whether the agent really follows a rule when it's tempted to break it.

**On site:** Before trusting a new builder, or before making a rule automatic: it checks that the rules in RULES.md are really followed.

It grades what the session actually did, not what it said. A result that isn't clear counts as a fail.

**When to use it:** Before you trust a new builder with real work, or before turning a rule into an automatic check.
