# adjudicate

Slash: `/adjudicate`. Folder: `skills/adjudicate/SKILL.md`.

Go through a review point by point: accept, reject, partly accept, or can't verify.

**On site:** The second review: **the foreman** goes through the outside reviewer's findings, and the accepted fixes go to the builder as a work order.

Every point is checked against the code first. How sure the reviewer sounded doesn't count as evidence.

**When to use it:** When the outside reviewer's findings come back.
