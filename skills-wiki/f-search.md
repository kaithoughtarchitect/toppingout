# f-search

Slash: `/f-search`. Folder: `skills/f-search/SKILL.md`.

Find Logbook cards about a topic.

**On site:** The Logbook: any time. [[f-shift]] uses it to load the lessons that apply to a job.

Searches current cards only; older ones are in [[f-archive-search]].

**When to use it:** When you want to know what past jobs learned about a topic.
