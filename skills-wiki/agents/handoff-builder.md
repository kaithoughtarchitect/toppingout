# handoff-builder

Agent: `agents/handoff-builder.md`.

Write the handover notes so the next session can pick up the work.

**On site:** Used at the end of every job that has a next job, from `templates/HANDOFF-SESSION-BRIEF.md`; the answers to its quiz go in a separate file. A topping out writes none.

**When to use it:** At the end of every job that has a next job, to write the notes for the next session.
