# f-context

Slash: `/f-context`. Folder: `skills/f-context/SKILL.md`.

Get a quick, complete picture of a repo before working in it.

**On site:** The Logbook: when you're new to a repo, or before rethinking a plan. At a job's start, [[f-shift]] already does this for the job.

It only reads, never changes anything. It can trace features with code-explorer, and `--deep` also digs through the commit history.

**When to use it:** When you arrive at a repo you don't know, or before re-planning work.
