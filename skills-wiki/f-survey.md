# f-survey

Slash: `/f-survey`. Folder: `skills/f-survey/SKILL.md`.

Turn a rough request into clear decisions, one round of questions at a time.

**On site:** Before a job, step 1: turning an idea into decisions.

It settles each choice by checking the actual code, so the plan written next has no open questions.

**When to use it:** When a request is still vague or has open choices, before anyone writes the plan.
