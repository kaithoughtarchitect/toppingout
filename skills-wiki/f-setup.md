# f-setup

Slash: `/f-setup`. Folder: `skills/f-setup/SKILL.md`.

Install the method into a repo or upgrade it, write the repo profile, and prove the install.

**On site:** Before the first job, once per repo, and again for each upgrade (never while a job is open).

The first time, the skill isn't in the repo yet: tell the session to read the package's `skills/f-setup/SKILL.md` and follow it. It reads the repo for the gates, remotes and keys before asking you anything, never overwrites a file the repo already has, and never commits.

**When to use it:** When a repo should start running the method, or a newer package should go over an existing install.
